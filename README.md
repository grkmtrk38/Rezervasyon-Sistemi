# Corporate Reservation Management System 📅🏢

A comprehensive, web-based reservation management system developed using **.NET Core MVC** during my internship at the Meram Municipality IT Department. 

## ✨ Features
* **Interactive Calendar:** Integrated with FullCalendar for intuitive, drag-and-drop event and reservation management.
* **Conflict Prevention Algorithm:** Intelligent backend logic to prevent double-booking and overlapping reservations.
* **Approval Workflow:** Multi-tier authorization structure and approval mechanisms for administrators.
* **Admin Dashboard:** Centralized control panel for managing users, tracking reservations, and viewing reports.
* **Smart Assistant Integration:** Embedded smart assistant features to streamline the booking process.

## 🛠️ Tech Stack
* **Framework:** ASP.NET Core MVC
* **Database:** Entity Framework Core
* **Frontend:** HTML, CSS, Bootstrap, JavaScript (FullCalendar.io)

## 📂 Project Scope
This project was developed from scratch as part of a structured 20-day professional internship plan, covering everything from database modeling and CRUD operations to security testing and live deployment processes.
